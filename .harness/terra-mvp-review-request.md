# MVP 요구조건·평가기준 충족도 평가 요청 (terra)

- 평가자: openai-codex/gpt-6.1-terra (다른 모델로 대체하지 않는다)
- 대상 커밋: 217b94b
- 공고 원문·정리: 공모전-공고문-정리.md, notice/
- MVP: web/ (배포본), docs/기획서-초안.md, submission/

## 요청

1. 공고의 제출 요구조건을 항목별로 나열하고, 각 항목의 충족 여부(충족/부분/미충족)와 근거 파일을 적는다.
2. 공식 평가기준의 배점별로 현재 MVP의 예상 점수와 근거를 적는다. 총점을 100점 환산 백분율로 낸다.
3. 서명·개인정보 공란은 승인 전 원칙에 따른 것이므로 내용 평가와 분리해 기록한다.
4. 점수를 올리기 위해 마감 전에 할 수 있는 개선 3가지를 우선순위로 적는다.

결과는 .harness/judge/mvp-terra.json 과 JUDGE.md 표에 실제 모델명·실행 id와 함께 기록한다.
