# K-JIT 시연 영상 대본

3분 이내, 목소리 없음, 화면 아래 한국어 자막. 숫자는 저장본·실측 문서에 있는 값만 말한다. 재생은 밝은 화면, 실시간은 어두운 화면이다.

녹화 명령: `python scripts/demo_video.py --url http://127.0.0.1:5173/ --server-url http://127.0.0.1:5174/`
산출: `build/demo/k-jit-demo.mp4`, 브랜치 사본 `docs/video/K-JIT-시연영상.mp4`.

서버(`kjit.service.app`)는 띄운다. 이 저장소에는 `data/processed/models/rtd_quantile.joblib`와 운항 DB가 없다. 그래서 직접 입력 계산, 메일 선석 매칭, 질의응답은 서버가 "아직 준비 중"으로 답한다. 조항 추출과 지시문·요청서는 서버의 규칙·템플릿으로 나온다. LLM 키는 없다. 자막은 그 사실을 숨기지 않는다.
