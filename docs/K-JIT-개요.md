# K-JIT: 선석 가용 확률 예측 기반 적시 입항(JIT) 코파일럿

2026 해운·항만·물류 AX 혁신 아이디어 공모전(주최 한국해양진흥공사, 협력 LG CNS) 출품 주제이다. 이 문서는 팀원이 주제, 근거, 진행 상황을 한 번에 파악할 수 있도록 정리한 개요이다. 세부 근거와 수치는 문서 끝의 문서 지도에서 찾을 수 있다.

- 작성일: 2026-10-08
- 접수 마감: 2026-10-30(금) 14:00, kobcax.com 게시물 접수
- 대표 Track: 해운 AX 추천 (확정 전)
- 핵심 키워드: 예측/최적화, 탄소 규제 대응

## 1. 한 줄 요약

국내 벌크·탱커 항만에서 선석이 언제 비는지를 확률로 예측하고, 그 분포로 중소선사에 감속 도착 시각과 속도를 권고한다. 정박지에서 기다리며 버리는 연료와 CO2를 줄이고, 선석 유휴는 늘리지 않는 것이 목표이다.

## 2. 문제

1. **"hurry up and wait":** 선박은 용선계약의 신속 항해(utmost despatch) 의무와 먼저 온 순서 관행 때문에 선석이 비기 전에 정박지에 먼저 도착해 기다린다. 정박지 대기 중의 연료는 항해거리 없이 CO2만 늘린다.
2. **CII 강화:** IMO CII 감축률은 2027년 13.625%에서 2030년 21.5%로 해마다 강화된다. 대기시간 보정은 IMO Phase 2(2026~2028)에서 논의 중이며 아직 채택되지 않았다.
3. **국내 공백:** 국내에는 항만 앞 20해리 구간의 저속운항제(2025년 참여율 88.7%)만 있다. 접근 항해 전체에서 도착 시각을 맞추는 JIT 체계는 찾지 못했다. 싱가포르(2023-10 시행)와 호주 뉴캐슬항은 이미 운영 중이다.
4. **실측 근거 (2025-10~2026-09, 해수부 입출항 신고 129,831항차):**
   - 대산은 화물선 항차의 64.7%, 울산은 25.2%, 광양은 15.5%가 정박지를 거쳐 선석에 들어갔다.
   - 정박지를 거친 항차의 약 절반(대산 48.2%, 울산 46.7%, 광양 49.2%)이 12시간 넘게 선석을 기다렸다.

## 3. 무엇을 만드는가

| 단계 | 내용 |
|---|---|
| 예측 | 목적 선석에 붙어 있는 선박과 줄 선 선박들의 남은 체류를 분위수로 예측하고, 이어 붙여 선석이 비는 시각의 분포를 만든다 |
| 결정 | 일찍 도착할 때의 대기 연료와 늦게 도착할 때의 선석 유휴를 함께 따져, 위험 수준에 맞는 도착 시각과 속도를 권고한다 |
| 정산 | 절감 연료·CO2·CII 변화와, BIMCO JIT 조항(2021) 기준 체선료 정산 영향을 계산한다. 용선계약의 관련 조항은 LLM이 근거 문장과 함께 찾고 사람이 확인한다 |
| 협업 | 2단계에서는 항만과 선석계획을 공유하고 가상 대기열을 운영한다. 기존 저속운항제 인센티브를 JIT 참여로 넓히는 안을 함께 제시한다 |

사용자는 중소 벌크·탱커 선사 운항 담당, 용선자, 선박대리점, 항만공사 선석 담당이다.

## 4. 지금까지 확인한 것

| 단계 | 결과 | 문서 |
|---|---|---|
| A. 정박지 대기 실측 | 9개 항만 1년치. 대산·울산·광양에서 정박지 경유 항차의 약 절반이 12시간 이상 대기. 판정 기준을 바꿔도 43~51% 유지 | [실측-A](./실측-A-정박지대기-2026-10-08.md) |
| B. 선석 가용 확률 예측 | 잔여 출항 시간 분위수 GBM의 중앙값 오차 24.0h. 선석 이력 기준선 30.3h보다 21% 개선. CQR 보정 후 80% 구간 적중률 77.7% | [실측-BC](./실측-BC-선석예측-JIT백테스트-2026-10-08.md) |
| C. JIT 결정 백테스트 | 시험 2개월 1,253항차. 선석계획을 공유하고 위험 수준 0.1로 결정하면 완전 정보 상한의 56%(연료 1,927t, CO2 6,072t)를 얻고, 추가 선석 유휴는 합계 29시간 | [실측-BC](./실측-BC-선석예측-JIT백테스트-2026-10-08.md) |
| 정보 공유 효과 | 같은 위험 수준에서 선석계획 공유는 입항 선박만 볼 때보다 절감을 약 1.9배로 늘린다 | [실측-BC](./실측-BC-선석예측-JIT백테스트-2026-10-08.md) |

연간 환산(참고)은 4개 항만(대산·울산·광양·여천) 기준 연료 약 1.17만t, CO2 약 3.7만t이다. 시험 두 달의 비율을 연간 상한에 곱한 값이며 계절 변동은 반영하지 않았다.

주요 한계는 다음과 같다.

- 정박지 대기는 선행 선박 출항 시각으로 복원한 하한 추정이다.
- 선석 가용 시각의 80% 구간 적중률은 재보정 후 74%로 목표에 못 미친다.
- 선석계획 공유 조건은 앞 순번 선박의 순서와 도착을 미리 안다고 가정한다.
- 연료 계수는 근사값이다.

## 5. 차별성과 피한 영역

조사 결과 다음 영역은 주최 측이 이미 수행 중이거나, 상용화되었거나, 다른 응모작과 겹쳐 피하였다.

- **주최 측 AX 체험 4종:** 용선계약 조항 검토, 수리비 이상 탐지, 터미널 추가비용 산출, Laytime 정산
- **2025 실증 4건:** 위험물 예약, 터미널 통계, 컨테이너 손상 견적, 사이버보안
- **주최 측 지원·자체 사업:** 중소선사 CII 관리 바우처, 공급망 조기경보
- **부산항만공사 과제:** VBS 예약, ETA, 대체선박 추천, 환적 이상탐지
- **2026 다른 응모작:** 환적 장치계획, 리퍼, 장기체화, 화물창 판정

해진공은 AI-Born 실증 예시로 "접·이안 대기시간 예측"을 밝혔다. K-JIT는 그 예측을 선사의 속도 결정과 계약 정산까지 잇는 의사결정 계층을 맡는다.

## 7. 저장소 구조와 재현

```
kjit/                 분석 코드
  fetch_calls.py      해수부 선박운항정보 입출항 신고 수집 (항만·월 단위, 받은 쪽은 건너뜀)
  parse_calls.py      원문 XML → 항차 표
  measure_wait.py     정박지 경유 분류, 선석 대기 하한 추정 (A)
  fuel.py, savings.py JIT 감속 연료·CO2 절감 (가정 기반)
  berth_dataset.py    선석 점유 구간 복원, 예측 표본 (B)
  forecast.py         잔여 출항 시간 분위수 GBM + CQR (B)
  queue_backtest.py   대기열 몬테카를로 + 재보정 + 정책 백테스트 (C)
  snapshot.py         입출항 신고 주기 저장 (사전 기준선용)
  ulsan_positions.py  울산항 항내 선박위치 주기 수집 (검증용)
data/processed/*.csv  결과 요약표 (원본·중간 데이터와 모델은 저장소에 올리지 않음)
docs/                 조사·제안·실측 문서
```

재현하려면 공공데이터포털에서 아래 세 API를 각자 활용신청해야 한다. 모두 개발계정 자동승인이다. 신청 후 인증키를 `.env`에 `DATA_GO_KR_KEY=...`로 넣는다.

- 해양수산부_선박운항정보
- 해양수산부_항만시설사용정보
- 울산항만공사_항내 선박위치정보

```bash
uv sync
uv run python -m kjit.fetch_calls --start 2025-10 --end 2026-09
uv run python -m kjit.parse_calls
uv run python -m kjit.measure_wait
uv run python -m kjit.savings
uv run python -m kjit.berth_dataset
uv run python -m kjit.forecast
uv run python -m kjit.queue_backtest
```

수집에는 약 30분이 걸리고 원본 XML은 약 450MB이다.
