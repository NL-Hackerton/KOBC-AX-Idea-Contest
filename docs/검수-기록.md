### 영상·zip 리허설

- 시연 영상: 자동 조작 + 자막, 181초, 5.0MB(H.264). 장면: 근거 → 항만 현황 → 재생 결정(정보 조건 전환, 설명, 실제 결과) → 실시간 직접 입력 → 시뮬레이터 → CII → 계약·메일·정산·질의응답. 자막 숫자는 실측 문서의 고정값만 쓰고, 실시간 장면은 녹화 시점의 차 있는 선석을 API에서 골라 입력한다.
- 제출 zip: `k-jit.html` 5.02MB + `k-jit-demo.mp4` 4.96MB + `README.txt` = 5.3MB(서명 PDF 없이). 첨부 용량 제한은 주최 측 확인 전이다.

### 이번 검수에서 고친 것

- 수집이 도는 동안 실시간 권고가 최대 11초까지 늦어졌다(10초 기준 초과). Context 재생성은 1.5초뿐이었고, 원인은 결정 기록 INSERT가 수집의 쓰기 트랜잭션을 기다린 것이었다. 기록을 전용 쓰기 스레드로 옮긴 뒤 수집 중 12회 측정에서 최대 1.5초(상태 0.3~0.9초, 엔진 0.2~0.9초, 서버 로그).
- 실시간 항차 결정에서 선박 목록을 "직접 입력"으로 되돌리면 화면이 깨졌다(선택값이 없는 선박으로 폼을 채우려 함). 직접 입력이면 폼을 비우고 열어 두도록 고쳤다.
- 근거 표: 표본이 너무 적은 항만의 통계를 숨김(위 표). 질의응답의 대기 통계 도구도 같은 기준.
- 항차 결정 차트: 기간이 열흘을 넘으면 가로축 날짜 라벨이 겹쳤다. 눈금 간격을 화면 폭에 맞춰 고른다.
- 모바일 375px에서 CII·항만 현황·근거 화면이 옆으로 넘쳤다. 격자 열과 넓은 표를 상자 안에 가뒀다.
