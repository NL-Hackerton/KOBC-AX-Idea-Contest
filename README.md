# 2026 해운·항만·물류 AX 혁신 아이디어 공모전

## 주제: K-JIT 선석 가용 확률 예측 기반 적시 입항 코파일럿

국내 벌크·탱커 항만에서 선석이 언제 비는지를 확률로 예측하고, 그 분포로 중소선사에 감속 도착 시각과 속도를 권고한다. 정박지에서 기다리며 버리는 연료·CO2를 줄이고, 선석 유휴는 늘리지 않는 것이 목표이다.

**처음이면 [docs/K-JIT-개요.md](./docs/K-JIT-개요.md)부터 읽는다.** 문제, 근거, 지금까지의 결과, 남은 일, 재현 방법이 한 문서에 정리되어 있다.

## 코드

- `kjit/` 아래에 분석 코드가 있다. 실행 순서는 `fetch_calls` → `parse_calls` → `measure_wait` → `savings` → `berth_dataset` → `forecast` → `queue_backtest`이다. 재현 방법은 개요 문서 7절에 있다.
- 공공데이터포털 인증키는 `.env`에 둔다. `.env`는 git에서 제외되어 있다.
- 원본·중간 데이터와 모델은 저장소에 올리지 않는다. `data/processed/*.csv` 요약표만 올린다.
